# CLAUDE.md

## Goal
Build a working web service for the Kookmin AI Builder Challenge.

## Rules
- Keep the implementation simple and reliable.
- Do not introduce unnecessary dependencies.
- Check existing code before modifying it.
- After making changes, run the relevant tests/build.
- Do not claim something works unless it has actually been checked.
- Keep the UI responsive.
- Do not modify unrelated files.

## Git
- Make small, meaningful commits.
- Do not use `git reset --hard`.
- Do not delete existing work without confirmation.

## Deployment
- The final service must be deployable publicly.
