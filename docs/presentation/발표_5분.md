# PassFinder 5분 발표 대본

덱 `PassFinder_발표자료_청중용.pptx`(9장, 15:35 저장본)의 장 순서와 문구에 맞춘 말하기 대본이다. 배포 주소(alt-tab-mu.vercel.app)에서 실제로 되는 것만 말한다. 전체 4분 40초, 질의응답 5분.

사용자 결정(15:10): 가격은 과목당 2,900원(가설)으로 말하고, 같은 시험 비교·풀이 참고(FR-14·15)는 다음 단계로 말한다. 제출 PRD 6절의 "월 2,900원 제안"은 "과목당"으로 맞춰야 한다(PRD 담당 세션에 전달).

## 시연 준비

- 주소: https://alt-tab-mu.vercel.app/study/make.html
- 파일: `passfinder/public/demo/운영체제_체험교안.pdf`(팀이 쓴 10쪽). 범위 1~5쪽.
- 덱 4장 노트대로 미리 만든 결과(1~5쪽)로 풀이 → 채점 → 오답 복습을 보여 준다. 라이브 생성을 보여 주려면 범위를 6~10쪽으로 바꾼다(실측 16~39초, 화면 안내는 최대 1분).
- 15:03 공개 주소 확인 결과: 생성 18초, 버튼 연타 시 요청 1번, 새로고침 뒤 문제·결과 유지(추가 요청 0번), 채점·해설·근거 표시, 오답 복습 버튼 동작, 페이지 오류 0건.

## 말하지 않을 것

- 수요·전환율·매출 숫자, "대학생 1% 확보" 같은 시나리오
- 학점이 오른다는 주장
- 아직 안 되는 기능을 된다고 말하기(로그인, 기기 간 저장, 결제, 랭킹, 친구와 비교)
- 다른 서비스에 없는 기능이라는 단정

## 예상 질문과 짧은 답

| 질문 | 답 |
| --- | --- |
| 문제가 틀리면요? | 근거 문장이 교안에 있는지는 확인하지만 정답 자체는 보장하지 않습니다. 화면에 근거 쪽과 문장이 같이 나와 학생이 바로 확인할 수 있고, 같은 수업 학생끼리 검수하는 방식을 다음 단계로 설계해 두었습니다. |
| 친구와 같이 쓸 수 있나요? | 서버에 문제 묶음을 저장하고 다른 사람이 같은 문제를 풀어 서버에서 채점하는 기능까지는 오늘 공개 주소에서 확인했습니다. 공유 링크와 결과 비교 화면은 다음 단계이고, 서버·DB 설계와 코드는 브랜치에 준비돼 있습니다. |
| 첫 화면의 학습맵·랭킹·이용권은 뭔가요? | 샘플과 데모 화면입니다. 이번 제출 범위는 교안으로 문제 만들기부터 오답 복습까지이고, 랭킹·결제는 범위 밖입니다. |
| 기존 AI와 뭐가 다른가요? | 범위만 고르면 되고, 근거를 자동으로 대조하고, 만든 문제가 남아 오답만 다시 풉니다. 기능 하나하나가 유일하다기보다 시험 범위 공부 흐름에 맞춰 묶은 것이 다릅니다. |
| 비용은 얼마나 드나요? | 학교 생성형 AI 기준으로 한 번 만들 때 입력·출력 토큰에 따라 수십 원 수준이고, 다시 풀 때는 들지 않습니다. 정확한 원가는 호출 기록으로 다시 계산합니다. |
| 교안 저작권은요? | 시연은 팀이 만든 자료로 했고, 교안 원본을 다른 학생에게 배포하는 구조가 아닙니다. 상용화 전에 자료 처리·보관·삭제 절차를 검토합니다. |
| 왜 돈을 내나요? | 첫 문제는 무료이고 계속 풀고 싶을 때 냅니다. 이 가격은 가설이라 학생 5명에게 실제로 써 보게 하고 확인하겠습니다. |
