# PassFinder 발표 설계안

5분 발표(문제 1분, 해결·시연 2분, 차별점·사업성 1분, 구현 범위·한계 1분)와 질의응답 5분을 위한 설계안이다. 슬라이드는 이 순서대로 만든다. 수치와 결과는 `PRD.md`와 `docs/설계.md`가 정본이며, 배포 주소에서 확인하지 않은 결과는 [확인 후 채움]으로 남겨 두고 발표 전에 채운다.

## 대본

말로 하는 문장이다. 화면에 있는 글을 그대로 읽지 않는다.

1. 시험 2주 전, 교안 PDF가 200쪽입니다. 저희는 매 학기 과목마다 같은 일을 합니다. 읽고, 중요한 걸 고르고, 문제를 만들고, 맞혔는지 확인하고, 틀린 걸 다시 봅니다.
2. 요즘은 AI에게 문제를 만들어 달라고 합니다. 그런데 정답이 맞는지 아무도 확인해 주지 않고, 대화창을 닫으면 그 문제는 사라집니다.
3. PassFinder는 이 일을 나눕니다. 문제는 학생이 이미 쓰는 AI가 교안을 읽고 만듭니다. 같은 수업 친구의 AI가 한 번 더 검수합니다. 학생은 휴대폰에서 쉬운 개념부터 다섯 문제씩 풉니다.
4. (시연) 체험 과목 참여 코드를 넣으면 운영체제 스테이지 맵이 보입니다. 첫 스테이지만 열려 있습니다. 다섯 문제 중 네 개를 맞히면 별을 받고 다음 스테이지가 열립니다. 첫 유닛 다섯 스테이지는 무료이고, 여섯 번째부터 이용권을 안내합니다. 결제는 실제 돈이 나가지 않는 테스트 결제입니다.
5. 문제를 만든 사람의 AI가 먼저 검사하고, 다른 학생 두 명이 통과시킨 문제만 반 전체에 공개됩니다. 두 명이 불합격시키거나 신고가 세 번 쌓이면 숨겨집니다.
6. 운영자가 문제를 검수했다면 과목 하나에 4,300원 정도가 듭니다. 이용권 가격보다 비쌉니다. 그래서 검수를 학생 AI가 나눠 맡게 했고, 서버는 생성형 AI를 부르지 않습니다. 한 반에 AI를 쓰는 학생 한 명이 문제를 만들면 나머지는 참여 코드로 들어와 풀기만 합니다.
7. 처음 계획은 서술형 답을 AI 유사도로 채점하는 것이었습니다. 재 보니 틀린 답 아홉 개 중 일곱 개를 정답으로 처리했습니다. 그래서 단답형으로 바꿨습니다. [확인 후 채움: 배포 주소에서 확인한 기능과 남은 기능]
8. 다음은 스터디 한 곳에서 첫 유닛을 실제로 풀게 하고, 여섯 번째 스테이지에서 결제하겠느냐는 반응을 확인하는 것입니다.

## 시연 준비

- 배포 주소: [확인 후 채움]
- 체험 과목 참여 코드: [확인 후 채움] (`scripts/seed-demo.mjs` 출력)
- 시연용 새 계정은 발표 직전에 만든다. 가입은 확인 메일 없이 바로 된다.
- MCP 장면은 실제 연결 화면을 미리 녹화한다. 발표장 네트워크에서 AI 클라이언트 연결이 실패할 수 있기 때문이다. 녹화본은 실제 호출이어야 하며, 녹화 일시를 화면에 남긴다.
- 실패 대비: 배포 주소가 열리지 않으면 같은 흐름의 녹화본으로 대체하고, 대체했다고 말한다.

## 말하지 않을 것

- 수요·전환율·매출 숫자(확인하지 않았다). "대학생 1% 확보" 같은 시나리오.
- 학점이 오른다는 주장.
- 확인하지 않은 기능을 된다고 말하기. 선택 기능(FR-07~11)은 하지 않았다고 말한다.
- 다른 서비스에 없는 기능이라는 단정.

## 예상 질문과 답

| 질문 | 답 |
| --- | --- |
| AI가 만든 문제가 틀리면요? | 만든 사람의 AI가 체크리스트로 먼저 거르고, 서버가 근거 쪽과의 관련성과 중복을 확인합니다. 다른 학생 두 명이 통과시켜야 모두에게 공개되고, 불합격 두 번이나 신고 세 번이면 숨겨집니다. 다만 근거 관련성 검사는 정답 오류를 잡지 못한다는 것도 측정했습니다. 그래서 공개 조건을 사람 쪽 검수에 둡니다. |
| AI 클라이언트가 없는 학생은 못 쓰나요? | 문제를 만드는 학생 한 명만 있으면 됩니다. 나머지는 참여 코드로 들어와 웹에서 풉니다. 검수에도 AI가 필요하다는 점은 남은 약점이고, 다음 단계로 웹에서 사람이 근거를 보고 통과를 누르는 방식을 검토합니다. |
| 교안 저작권은요? | PDF 원본은 저장하지 않고 글자만 분석합니다. 문제는 같은 수업에 참여한 사람끼리만 씁니다. 법률 검토는 아직 하지 않았습니다. |
| 서버는 AI를 정말 안 쓰나요? | 생성형 AI는 부르지 않습니다. 교안 검색과 근거 확인에 임베딩 하나만 씁니다. 교안 100쪽 분석에 1원도 들지 않는 수준입니다. |
| 왜 돈을 내나요? | 첫 유닛은 무료로 풀어 보고, 시험 범위 끝까지 이어 풀고 싶을 때 과목당 2,900원을 냅니다. 이 가격은 아직 가설이고, 스터디에서 실제 반응을 확인하려 합니다. |
| 계정 두 개로 혼자 검증하면요? | 막지 못합니다. 참여 코드를 아는 사람만 과목에 들어오게 해 범위를 좁혔고, 이 약점은 PRD에 적어 두었습니다. |
